## New to shaders?

<Steps>
  <Step title="Install a shader loader">
    Follow [Install Iris](/using/install-iris/) or [Install OptiFine](/using/install-optifine/). Minecraft cannot load shaderpacks without one.
  </Step>
  <Step title="Pick a shaderpack">
    [Choosing a shaderpack](/using/choosing-a-shaderpack/) covers style, performance cost and where to download packs safely.
  </Step>
  <Step title="Make it run well">
    [Performance](/using/performance/) shows which settings cost the most frames. If something looks wrong, start with [Troubleshooting](/using/troubleshooting/).
  </Step>
</Steps>
